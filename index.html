About

Hey, I'm Vishnu.

I'm a Cloud & AI Engineer who builds, breaks, writes, and speaks — all about AWS. My day-to-day is architecting production workloads and shipping with Gen AI, Bedrock, and Agentic AI frameworks.

At SUDO Consultants I work across security, FinOps, and modernization — and I hold 14 AWS certifications (every Professional & Specialty exam), plus Terraform, Vault, Fortinet, and Oracle Cloud. Multi-cloud, security-first.

Beyond the console, I'm an active AWS Community Builder (Security), I publish deep technical write-ups, and I speak at AWS Community Days across India and on international stages. I also lead Golden Jackets India as Chapter Lead — a community of Indian engineers who've earned every active AWS certification.

I also created and published the AWS Resilience Hub Kiro Power — officially listed on kiro.dev/powers, bringing resilience assessment capabilities to Kiro IDE users worldwide.

Key Highlights

Real-World Impact

🚨
Emergency DR Recovery with ColdSnap
Led emergency AWS DR recovery during a regional degradation — recovered 21 EBS snapshots (~7-10TB) via block-level EBS Direct API downloads after CreateVolume, cross-region snapshot copy, cross-region AMI copy, and VM Export all failed, with AWS Support confirming no native fix existed.
🔐
KMS Key Migration for VM Export
Solved a VM Export blocker where source volumes were encrypted with the AWS-managed KMS key — downloaded snapshots as unencrypted raw images via ColdSnap, re-uploaded and re-encrypted with a customer-managed key, then completed VM Export for on-prem delivery.
⚡
Kiro Power — AWS Resilience Hub
Built an open-source agentic IDE integration bundling 4 MCP servers (aws-mcp, aws-docs, aws-repost, aws-pricing) and 4 skills, automating account-wide resiliency scanning, GenAI failure-mode assessment, WAF best-practice mapping, and cost-quantified remediation.
🤖
AWS Transform for Lambda Modernization
Used AWS Transform for customer Lambda runtime migration/modernization — upgrading legacy runtimes with automated code transformation powered by AWS's agentic AI service.
💰
AWS FinOps Agent Deployment
Deployed AWS's native FinOps Agent to automate customer cost reporting and drive cost optimization recommendations — enabling real-time spending visibility and actionable savings insights.
📁
AWS Transfer Family Web Apps
Set up AWS Transfer Family web apps for a customer — enabling secure, browser-based file sharing for the customer's front-end file exchange needs with S3 Access Grants and IAM Identity Center integration.
