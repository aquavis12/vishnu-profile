Mastering Amazon EC2

Compute, Storage, Networking and Recovery

Most EC2 guides teach you to launch a server. This one teaches you to keep it alive.

A practical, hands-on guide to Amazon EC2 — from your first launch to real-world recovery. Built on field stories from production AWS work and the AI tools AWS now builds into everyday operations. Launching an instance takes two minutes; running it well takes the right network, safe access, the right disks, backups you can trust, and a plan for the day something breaks.

What you'll learn

  • Launch EC2 safely with IAM roles, VPCs, subnets, and security groups
  • Connect every way: SSH, EC2 Instance Connect, Session Manager, Fleet Manager, RDP, and the Serial Console
  • Fix failed connections — and get back in when the key pair is lost
  • Pick instance types and pricing options that keep your AWS bill under control
  • Protect data with EBS snapshots, AMIs, Data Lifecycle Manager, and AWS Backup
  • Monitor, secure, and scale with CloudWatch, load balancers, and Auto Scaling
  • Use AI on AWS: Amazon Q for instance advice, and CloudWatch investigations for root causes
  • Migrate servers with AWS Transform MGN and recover with Elastic Disaster Recovery

Inside the book

  • Part 1 — Foundations (Ch. 1–5): the cloud and EC2, IAM, your first launch, networking, and connecting to instances
  • Part 2 — Configuring EC2 (Ch. 6–12): instance types and pricing, launch options, user data, tags, Elastic IPs, placement
  • Part 3 — Storage and images (Ch. 13–18): EBS volumes, snapshots, Data Lifecycle Manager, copying volumes, AMIs
  • Part 4 — Operations (Ch. 19–23): creating instances, Amazon Q for EC2, CloudWatch and AI-powered investigations, security, Auto Scaling
  • Part 5 — Migration and recovery (Ch. 24–27): the 7 Rs, AWS Transform MGN and its AI agent, Elastic Disaster Recovery, AWS Backup
  • Capstone (Ch. 28): host a simple website and back it up — plus appendices on a production checklist and remote access with Client VPN and Verified Access
